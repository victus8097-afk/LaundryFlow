# LaundryFlow — مشروع جامعي بسيط

تطبيق Flutter عربي لإدارة طلبات مغسلة: إضافة طلب، عرض الطلبات، فتح التفاصيل وتحديد الطلب كجاهز للاستلام.

## الفكرة

أربع شاشات فقط، وإدارة الحالة باستخدام `setState` وقائمة `List<LaundryOrder>` داخل الرئيسية. لا توجد حزم خارجية لإدارة الحالة أو التخزين ولا حسابات أو خادم. `flutter_localizations` من Flutter SDK لتعريب الواجهة، والصور وخط Cairo مرفقان محليًا.

الطلبات مؤقتة: تُمسح عند إغلاق التطبيق أو الرجوع من الرئيسية إلى الترحيب وفتح الرئيسية مجددًا. لا تُقرأ بيانات النسخة القديمة.

## المتطلبات السبعة

| المتطلب | التطبيق |
| --- | --- |
| Home / Welcome | شاشة ترحيب بصورة وزر بدء، ورئيسية تعرض الطلبات |
| Cards وصور وأيقونات وأزرار | صور الترحيب والرئيسية وبطاقات الطلبات وأزرار الإضافة والحفظ |
| Form وValidation | اسم من حرفين، هاتف من 9 إلى 15 رقمًا، وعدد قطع من 1 إلى 100 |
| عرض ديناميكي | `ListView.builder` في الرئيسية يعرض قائمة الطلبات |
| Drawer | القائمة في الرئيسية للوصول إلى الطلبات أو إضافة طلب |
| Navigator.push وNavigator.pop | فتح الشاشات وإرجاع الطلب الجديد أو نتيجة تحديث الحالة |
| تنظيم واضح | نموذج واحد، أربع شاشات، وودجتان مشتركتان |

## الملفات

```text
lib/
  main.dart                       إعداد التطبيق والثيم واللغة
  models/
    laundry_order.dart            بيانات الطلب
  screens/
    welcome_screen.dart           الترحيب
    home_screen.dart              القائمة وإدارة الحالة
    add_order_screen.dart         نموذج الإضافة والتحقق
    order_details_screen.dart     التفاصيل وتحديد الطلب كجاهز
  widgets/
    custom_drawer.dart            قائمة التنقل
    order_card.dart               بطاقة الطلب
```

## مسار الاستخدام

ابدأ إدارة الطلبات ← طلب جديد ← أدخل البيانات واحفظ ← افتح بطاقة الطلب ← حدده كجاهز للاستلام.
